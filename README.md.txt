# Инженерный помощник ННБ (Экосистема КНБК)

Интерактивное веб-приложение на базе **Streamlit** для инженеров по наклонно-направленному бурению.

## Функционал:
1. **Матрица рисков и решений**: Пошаговый экспертный чек-лист при входном контроле КНБК, опрессовке и технологических осложнениях.
2. **Калькулятор УМК**: Модуль динамического пересчета момента затяжки резьбовых соединений КНБК при отклонении геометрии натяжного троса.
